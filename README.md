# Shivani Dhotre — Portfolio Website

A personal portfolio website built with **Flutter Web**, showcasing my skills, experience, education, and projects as a Flutter Developer.

## Live Demo

> Coming soon via Firebase Hosting

## Features

- Responsive design for mobile, tablet, and desktop
- Smooth scroll navigation via navbar
- Animated hero section with floating avatar and rotating rings
- Experience section with tech stack
- Education section with card layout
- Recent Works / Projects section
- Skills section with 20+ technology icons
- Contact form with email integration
- Hire Me card linking to contact section

## Sections

| Section | Description |
|---|---|
| Hero | Introduction, "See my work" and Email buttons |
| About | Brief background and stats |
| Experience | Current role at Brilliantech Software |
| Education | BE, Diploma, and HSC details |
| Recent Works | Flutter app projects |
| Skills | Technologies I work with |
| Contact | Message form with email |

## Tech Stack

- **Flutter Web**
- **Dart**
- **Firebase Hosting** (deployment)
- **url_launcher** (email & links)
- **flutter_svg** (skill icons)

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run on web
flutter run -d chrome

# Build for production
flutter build web --release
```

## Deployment (Firebase Hosting)

```bash
flutter build web --release
firebase deploy
```
